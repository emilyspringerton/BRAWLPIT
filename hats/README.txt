Drop .hat files here to wear them in BRAWLPIT.

1. Draw a hat at https://wotan.okemily.com/hat-studio.html
2. Click "Download .hat for BRAWLPIT"
3. Put the file in this folder (or set BRAWLPIT_HATS_DIR to another folder)
4. Start the game. At character select, Up/Down cycles: No Hat, Blue, Red, Green, then your hats.

Up to 16 hats are loaded. Hats show in local matches (they are not synced to network opponents yet).
